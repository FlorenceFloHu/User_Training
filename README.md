# 培训视频网站使用说明

网站结构：**首页（所有项目） → 项目 → 章节 → 视频**

## 1. 上传视频（免费）
视频文件很大，建议放在免费视频平台上，再把链接粘贴到网站里：

- **YouTube**（推荐）：上传后把"公开范围"设为 **不公开（Unlisted）**，只有拿到链接的人能看到。
- **Vimeo** 免费版，或
- **Google Drive**：上传后点 **共享 → 一般访问权限 → 知道链接的任何人**。

## 2. 在 videos.js 里添加项目和视频
用文本编辑器打开 `videos.js`（Mac 自带的"文本编辑"可以用，记得先点 **格式 → 制作纯文本**；更推荐免费的 VS Code）。

- 最上面的 `SITE` 改网站标题和说明。
- `PROJECTS` 里每一段 `{ name: ... }` 是一个项目，可以写项目名称和说明。
- 每个项目里的 `sections` 是章节，章节里的 `videos` 是视频。
- 把视频链接粘贴到 `link: ""` 的引号中间。
- **新增项目**：复制一整段项目，粘贴到后面，再修改内容。
- **新增视频**：复制一行 `{ title: ... },`，再修改内容。
- 逗号、引号、括号要和示例保持一致，否则页面会是空白。

## 3. 免费发布到网上

### 方法 A：Netlify Drop（最简单，不需要写代码）
1. 打开 https://app.netlify.com/drop
2. 把整个 **training-site** 文件夹拖到网页上。
3. 按提示注册免费账号，网站才能一直在线。你会得到类似 `https://你的名字.netlify.app` 的网址，可以在 **Site configuration → Change site name** 里改名。
4. 以后修改：改好 `videos.js` 后，在 Netlify 打开你的网站 → **Deploys** → 再把文件夹拖进去。

### 方法 B：GitHub Pages
1. 注册免费 GitHub 账号，新建一个 **public** 仓库。
2. **Add file → Upload files**，上传 `training-site` 里的所有文件。
3. **Settings → Pages → Branch: main → Save**，网址是 `https://<用户名>.github.io/<仓库名>/`。

## 小提示
- 可以直接把某个项目的链接发给对应的人，例如 `你的网址/#2` 会直接打开项目 2。
- "已观看"进度只保存在每个人自己的浏览器里，你看不到别人的进度。
- 拿到网站链接的人都能打开网站。
